# Pixel Studio

A small pixel art editor with a resizable grid.

## Features

- Grid sizes of 16, 24, 25, 32, 48 and 64 pixels square
- A checkerboard background with grid lines on the smaller sizes
- Sixteen colour swatches and an eraser
- Click and drag to paint, with pointer and touch support
- Undo history for the last thirty strokes
- Clear the canvas
- Export the artwork as a transparent PNG

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    drawing and export logic
```

## Tech

Plain HTML, CSS and JavaScript with the Canvas API.
